# Staff API Flow

Send requests to retrieve orders, prioritize and prepare, retrieve dishes for an order, display dish ingredients, and assemble the order.

## 1. Display an Order

### Request

The client sends an HTTP request to `https://{{baseUrl}}/orders` to get a list of orders. 

Include the `status` filter to retrieve orders in the "Received" status. You can also specify the `priority`, `table_number`, `status`, and `dish_ids` fields to retrieve more detailed information for each order.

```
curl -X GET 'https://{{baseUrl}}/orders?fields=table_number|status|priority|dish_ids&filter=status.eq~Received'
```

### Response

If the request was successful, the server responds with a `200 OK` status code with the response body containing each order's `id`, `table_number`, `status`, `priority`, and `dish_ids`.

```json
{
    "results": [
        {
            "id": "6b03612d2adf95b5cb2ffd1e",
            "table_number": 25,
            "status": "Received",
            "priority": 3,
            "dish_ids": [
                "6af1f160b7c431c173cf9d55"
            ]
        },
        {
            "id": "6af1f161b7c431c173cf9df8",
            "table_number": 4,
            "status": "Received",
            "priority": 3,
            "dish_ids": [
                "6af1f160b7c431c173cf9d58",
                "6af1f160b7c431c173cf9d80",
                "6af1f160b7c431c173cf9dc8",
                "6af1f160b7c431c173cf9d6d"
            ]
        },
    ] 
}
```

## 2. Prioritize an Order

### Request

The client sends a PUT HTTP request to `https://{{baseUrl}}/orders/:id` and specifies a new value in the `priority` field to update the order's priority.

```
curl -X PUT 'https://{{baseUrl}}/orders/:id' \
-H 'accept: application/json' \
-H 'Content-Type: application/json' \
-d 
{
    "table_number": 25,
    "status": "Received",
    "priority": 1,
    "dish_ids": [
        "6af1f160b7c431c173cf9d55"
    ],
}
```

### Response

If the request was successful, the server responds with a `200 OK` status code with the response body containing the updated `priority` field. 

In the example below, the `priority` was successfully changed to 1. (Previously, the `priority` was 3.)

```json
{
    "id": "6b03612d2adf95b5cb2ffd1e",
    "created_at": "2026-11-22T21:39:57.062Z",
    "updated_at": "2026-11-22T22:44:53.089Z",
    "scheduled_at": null,
    "table_number": 25,
    "status": "In Progress",
    "priority": 1,
    "dish_ids": [
        "6af1f160b7c431c173cf9d55"
    ],
}
```

## 4. Prepare Orders by Station

### Request

The client sends an HTTP request to `https://{{baseUrl}}/orders/:id/dishes` and includes the `fields` parameter to identify the station for each dish in the order. 

```
curl -X GET 'https://{{baseUrl}}/orders/:id/dishes?fields=name|station'
```

### Response

If the request was successful, the server responds with a `200 OK` status code with the `station` identified.

```json
{
    "results": [
        {
            "id": "6af1f160b7c431c173cf9d55",
            "name": "Bruschetta al Pomodoro",
            "station": "cold"
        }
    ],
    "total_results": 1
}
```

## 5. Display Dish Ingredients

### Request

The client sends an HTTP request to `https://{{baseUrl}}/dishes/:id/ingredients` to identify ingredients in a dish associated with the order.

```
curl -X GET 'https://{{baseUrl}}/dishes/:id/ingredients'
```

```
    "table_number": 25,
```
